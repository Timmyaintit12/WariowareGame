This is a basic WarioWare style game made in godot.<br>
It consists of 3 minigames that you have to complete to beat the game. You have 5 lives to complete the minigames<br>
<img width="371" height="212" alt="Screenshot 2026-09-17 105135" src="https://github.com/user-attachments/assets/dd49760a-8476-4445-8f4d-02d6f285ec2c" /><br>
It runs in itch.io (linked below or you can download it and run it yourself.<br>
https://toma12345.itch.io/warioware-game <br>
In minigame 1 you have to jump on the platforms and collect all the mushrooms. In minigame 2 you have to click all the mushrooms in time. In minigame 3 you have to dodge the falling mushrooms while the timer is going.<br>
